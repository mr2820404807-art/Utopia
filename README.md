# 乌托邦 · UTOPIA — 3D 地球大战略游戏

基于 Three.js 的 3D 地球文明时代3式（AoH3）大战略游戏。选一个国家，从 2026 年开始征服世界。

**在线游玩**: https://mr2820404807-art.github.io/Utopia/

## 快速开始

- **在线版**：直接打开上面的链接
- **本地版**：双击项目目录下的 `启动游戏.bat`（需已安装 Python）
- 注意：不能直接双击 index.html——ES 模块无法在 file:// 下运行

## 核心玩法

| 系统 | 说明 |
|---|---|
| 战斗 | 多日战斗解算：兵力×军事科技×堡垒×军官，伤亡/撤退/围城/占领 |
| AI | 241 国全部有经济/驻军/性格（扩张/守成/均衡），自动宣战、进攻、求和 |
| 外交 | 关系矩阵、战争借口、宣战、和谈（白和/割地/傀儡）、同盟、停战 |
| 经济 | 省份经济→国库、军队维持费、预算三政策、贷款、法律 |
| 占领消化 | 占领区动荡度，满 100 起义复国——速推会被后方拖垮 |
| 科技 | 4 方向 26 项前置科技树，效果作用于战斗与经济 |
| 胜负 | 控制 40% 世界领土或消灭全部列强=胜利；丢光省份=战败 |

## 视听系统

- 太阳方向光昼夜晨昏线 + 夜面城市灯光 + 太阳巡天
- 程序化云层（fBm 噪声 + 纬度气候带，受光照，近景淡出）
- 太阳感知大气散射（向阳蓝辉/晨昏暖橙/夜侧深蓝）
- **双地图风格**：📜 卫星 ⇄ 古典羊皮纸（罗盘玫瑰/经纬网/墨线海岸）
- 世界编年史、程序化音效（可静音）

## 数据与工程

- `data/provinces_v2.geojson`：Natural Earth 10m 预处理（3300 行政区/251 国，DP 简化，`make_provinces_v2.py` 生成）
- `js/` 模块化系统层：state/nations/combat/diplomacy/ai/economy/tech/victory/mapmodes/data/audio
- 数值参照《文明时代3》gameValues 配置校准
- 存档 v2 格式含国家/战争/外交/编年史，自动迁移 v1 旧档

## 操作

- 拖拽旋转地球，滚轮/双指缩放；放大后点击省份，缩小后点击国家
- 左侧：6 种地图模式 + 地图风格切换；右侧栏：省份操作
- 底栏：军官/预算/法律/静音；右侧按钮：科技/编年史/战争
- 空格暂停，+/- 调速
